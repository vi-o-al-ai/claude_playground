Apple Music → YouTube

Turn an exported Apple Music playlist into a real playlist on your own YouTube account.

1 Bring in your playlist

In the Apple Music desktop app, select a playlist and choose File → Library → Export Playlist… , then drop that file here. Or just paste lines like Song Title - Artist .

2 Connect your YouTube account

YouTube has no “just log in” option for third-party sites — you need a free Google Cloud OAuth client of your own. It is a five-minute, one-time setup.

How to get a client ID
  1. Open Google Cloud Console and create a project.
  2. Under APIs & Services → Library , enable the YouTube Data API v3 .
  3. Under OAuth consent screen , pick External , fill in the basics, and add yourself under Test users .
  4. Under Credentials → Create credentials → OAuth client ID , choose Web application .
  5. Add this page's origin ( ) to Authorised JavaScript origins .
  6. Copy the client ID here. It is stored only in this browser, and no client secret is ever needed.
